# usage-rs

Rust port of `shared/usage.ts`, bridged with napi-rs. Generated by rust-anything; `src/port.rs`
delegates to `relay_core::shared::usage`, and `src/port/args.rs` turns the bindings' JSON
(`undefined` members, `{"$num": ...}` markers for NaN, ±Infinity and -0) into the relay-core types.

A missing `now` is `Date.now()`, read from `src/port/pinned.rs`. `windowHolds` and `remaining`
name their window `window` (the TS `w` clashes with the generated wire writer). `suggestedAccount`
returns the caller's own account object.

## Loop

Cases are the calls the tests make plus `inputs.jsonl` (readings and windows around the fresh,
last-known and reset edges, with and without `now`). Generated inputs are off (`--count 0`):
they pass arbitrary JSON where the TS types name `AccountUsage`, `Account` and `RelaySettings`.

  --from-tests -- node --import tsx --test tests/automatic-target-ranking.test.ts \
  tests/fleet-continuation.test.ts tests/overview.test.ts tests/switch-strategy.test.ts tests/usage.test.ts
