# lost-found-rs

Rust port of `shared/lost-found.ts`, bridged with napi-rs. Generated by rust-anything;
`src/port.rs` delegates to `relay_core::shared::lost_found`, and `src/port/args.rs` turns the
bindings' JSON (`undefined` members, `{"$num": ...}` markers) into the relay-core types.

The TS reads ledger counts as its own `LedgerCounts` (no `responses`, `cost` optional and read as
`cost ?? 0`); relay-core's ledger types require both, so the port fills them as the TS reads them.
Accounts the tests cast from partial objects may lack `auth.checkedAt`, which nothing here reads.

## Loop

Cases are the calls the tests make plus `inputs.jsonl`: generated inputs of the functions whose
arguments are plain numbers, strings or `unknown` (`tierOf`, `nextTier`, `modelFamily`, `addDays`,
`mondayOf`, `validLostItem`). Generated inputs are off otherwise (`--count 0`): they pass arbitrary
JSON where the TS types name `LostFoundInput`.
