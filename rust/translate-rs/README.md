# translate-rs

Rust port of `shared/i18n/translate.ts`, bridged with napi-rs. Generated by rust-anything;
`src/port.rs` delegates the formatting to `relay_i18n` (`crates/relay-i18n`).

## Functions

- `registerCatalog` (`shared/i18n/translate.ts:16`)
- `setPseudo` (`shared/i18n/translate.ts:22`)
- `formatRich` (`shared/i18n/translate.ts:66`)
- `loadCatalog` (`shared/i18n/translate.ts:94`)

`tFor` stays in TypeScript here (it returns a function). Its port, `relay_i18n::translate`, is
checked against every message in every language by `cargo test -p relay-i18n --test golden`.

## Loop

Cases come from `inputs.jsonl` (real locales, ids and string/number values, as the TS types
say) plus the calls the i18n tests make; generated inputs are off (`--count 0`) because they
pass arbitrary JSON where the types allow only locales and message ids.

```sh
rust-anything record rust/translate-rs --count 0 --pin-clock --inputs rust/translate-rs/inputs.jsonl \
  --from-tests -- node --import tsx --test tests/i18n*.test.ts
rust-anything build rust/translate-rs
rust-anything diff rust/translate-rs
rust-anything gate rust/translate-rs
```
