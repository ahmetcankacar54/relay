# percent-rs

Rust port of `shared/percent.ts`, bridged with napi-rs. Generated by rust-anything;
`src/port.rs` delegates to `relay_core::shared::percent` (`crates/relay-core`), with the language
read by `relay_i18n::Locale::parse`.

- `formatPercent` (`shared/percent.ts:12`)
- `percentUsed` (`shared/percent.ts:26`)
- `usedWord` (`shared/percent.ts:33`)
- `formatUsed` (`shared/percent.ts:36`)

## Loop

The original is recorded through `original.ts`, which registers every catalog first as the app
and the CLI do (alone, `tFor` would answer English for every language, while `relay-i18n` embeds
all catalogs). Cases come from `inputs.jsonl` (all 15 locales × rounding edges, NaN, ±Infinity,
-0, `undefined`) plus the calls the tests make; generated inputs are off (`--count 0`) because
they pass arbitrary JSON as the `Locale`. `usedWord` is an arrow-function const, so
`--from-tests` cannot capture it; `inputs.jsonl` covers it.

```sh
rust-anything record rust/percent-rs --count 0 --pin-clock --module original.ts --inputs inputs.jsonl \
  --from-tests -- node --import tsx --test tests/percent.test.ts tests/tray.test.ts tests/menu-bar-title.test.ts \
  tests/widget-snapshot.test.ts tests/mascot.test.ts tests/automation-status.test.ts tests/lost-found.test.ts \
  tests/statusline.test.ts
rust-anything build rust/percent-rs
rust-anything diff rust/percent-rs
rust-anything gate rust/percent-rs
```
