# account-state-rs

Rust port of `shared/account-state.ts`, bridged with napi-rs. Generated by rust-anything;
`src/port.rs` delegates to `relay_core::shared::account_state` (`crates/relay-core`) and reads the
arguments with `rust/parity-args` (JS markers such as `undefined` keys and `NaN` numbers).

## Loop

Cases come from `inputs.jsonl` (well-typed accounts, usage readings and sign-in flows) plus the
calls the tests make. Generated inputs are off (`--count 0`): they pass objects that are not
`Account`/`AccountUsage` at all (`{"a": "b"}`, `null`). `tests/desktop-usage.test.ts` and
`tests/sign-in-renewal.test.ts` are left out because their fixtures are `as Account` casts missing
required fields (`kind`, `group`), which the typed Rust API rejects; `inputs.jsonl` covers the
same shapes.

```sh
rust-anything record rust/account-state-rs --count 0 --pin-clock --inputs rust/account-state-rs/inputs.jsonl \
  --from-tests -- node --import tsx --test tests/account-health.test.ts tests/account-state.test.ts
rust-anything build rust/account-state-rs
rust-anything diff rust/account-state-rs
rust-anything gate rust/account-state-rs
```
