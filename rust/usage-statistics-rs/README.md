# usage-statistics-rs

Rust port of `shared/usage-statistics.ts`, bridged with napi-rs. Generated by rust-anything;
`src/port.rs` delegates to `relay_core::shared::usage_statistics`, and `src/port/args.rs` turns the
bindings' JSON (`undefined` members, `{"$num": ...}` markers) into the relay-core types.

## Functions

- `usageIdentity` (`shared/usage-statistics.ts:18`)
- `historyIdentity` (`shared/usage-statistics.ts:32`)
- `usageSample` (`shared/usage-statistics.ts:79`)

`identityOwners` stays in TypeScript here (`js_only`): it returns a `Map`, which the binary wire
carries as a plain object. Its port, `usage_statistics::identity_owners`, is checked by the ported
unit tests (and runs inside the tempo, statistics and lost-found parity crates).

Test fixtures cast from partial objects may lack `kind`; the port fills it, as nothing here reads it.

## Loop

Cases are the calls the tests make plus `inputs.jsonl` (sign-in and Claude app identities: uuid,
email trimming and case, missing org). Generated inputs are off (`--count 0`): they pass arbitrary
JSON where the TS types name `Account` and `AccountUsage`.
