# tray-rs

Rust port of `shared/tray.ts`, bridged with napi-rs. Generated by rust-anything; `src/port.rs`
delegates to `relay_core::shared::tray`, and `src/port/args.rs` turns the bindings' JSON
(`undefined` members, `{"$num": ...}` markers) into the relay-core types.

The TS defaults are filled in: `language` `"en"`, `now` `Date.now()` (read from
`src/port/pinned.rs`), `max` `TRAY_NAME_MAX`, `name` `"Max"`, `estimated` false. An account cast
from a partial object (`{ id, name } as Account`, as `menuBarPreview` builds one) gets empty values
for the fields the tray never reads, where relay-core's `Account` requires them.

## Known differences

- `trayResetClock` with an empty time zone: the TS keys its cached formats by
  `` `${language}:${timeZone ?? ""}` ``, so an empty zone reuses the system-zone format once one
  was built for that language (any title without a zone builds it) and answers `undefined` only
  before that. relay-core always reads an empty or unknown zone as the system's. The planning time
  zone is never empty; the recorded cases run with the cache warm and match.
- An offset time zone such as `"+03:00"` (newer `Intl` accepts it) is unknown to relay-core's zone
  table and falls back to the system's zone; Relay's planning zones are IANA names.

## Loop

The original is recorded through `original.ts`, which registers every catalog first as the app and
the CLI do (alone, `tFor` would answer English for every language, while `relay-i18n` embeds all
catalogs). Cases are the calls the tests make plus `inputs.jsonl` (all 15 locales × token and
dollar edges, reset clocks in five zones plus an unknown and an empty one, titles, tooltips, menus
and usage labels for fresh, full, stale and last-known readings with every title item, a switch,
Claude closed, read ages from just now to days, short names with emoji and BOMs, and odd
`menuBarItems` values). Generated inputs are off (`--count 0`): they pass arbitrary JSON where the
TS types name `TraySnapshot` and `AccountUsage`.

```sh
rust-anything record rust/tray-rs --count 0 --pin-clock --module rust/tray-rs/original.ts \
  --inputs rust/tray-rs/inputs.jsonl \
  --from-tests -- node --import tsx --test tests/tray.test.ts tests/tray-panel.test.ts \
  tests/menu-bar-title.test.ts tests/mascot.test.ts
rust-anything build rust/tray-rs
rust-anything diff rust/tray-rs
rust-anything gate rust/tray-rs
```
