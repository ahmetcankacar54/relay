# desktop-account-rs

Rust port of `shared/desktop-account.ts`, bridged with napi-rs. Generated by rust-anything;
`src/port.rs` delegates to `relay_core::shared::desktop_account` (`crates/relay-core`) and reads the
arguments with `rust/parity-args`.

## Functions

- `desktopAccountFor` (`shared/desktop-account.ts:11`)

It returns the caller's own account object, as `Array.prototype.find` does.

## Loop

Cases come from `inputs.jsonl` (case-folded ids, missing and empty organizations) plus the calls
the tests make. Generated inputs are off (`--count 0`) because they are not `Account` lists.
`tests/lost-found.test.ts` is left out: its accounts are `as Account` casts whose `auth` lacks
the required `checkedAt`, which the typed Rust API rejects.

```sh
rust-anything record rust/desktop-account-rs --count 0 --pin-clock --inputs rust/desktop-account-rs/inputs.jsonl \
  --from-tests -- node --import tsx --test tests/token-attribution.test.ts tests/lost-found-card.test.ts tests/lost-pins.test.ts
rust-anything build rust/desktop-account-rs
rust-anything diff rust/desktop-account-rs
rust-anything gate rust/desktop-account-rs
```
