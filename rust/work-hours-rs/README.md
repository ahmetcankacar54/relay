# work-hours-rs

Rust port of `shared/work-hours.ts`, bridged with napi-rs. Generated by rust-anything;
`src/port.rs` delegates to `relay_core::shared::work_hours` (`crates/relay-core`) and reads the
planning settings with `rust/parity-args`.

- `shiftDate` (`shared/work-hours.ts:15`)
- `isWeekend` (`shared/work-hours.ts:20`)
- `workInterval` (`shared/work-hours.ts:28`)
- `dayStart` (`shared/work-hours.ts:45`)

## Loop

Cases come from `inputs.jsonl` (DST nights, overnight and skipped hours, Apia's missing day, in
20 zones) plus the calls the planning tests make; generated inputs are off (`--count 0`) because
they are not dates or `PlanningSettings`. Not covered: `shiftDate` on a date that does not
parse, where the TS throws and relay-core returns `""`.

```sh
rust-anything record rust/work-hours-rs --count 0 --pin-clock --inputs rust/work-hours-rs/inputs.jsonl \
  --from-tests -- node --import tsx --test tests/capacity-plan.test.ts tests/tempo.test.ts tests/day-plan.test.ts \
  tests/live-forecast.test.ts tests/adaptive-pace.test.ts tests/adaptive-replan.test.ts tests/adaptive-schedule.test.ts \
  tests/day-timeline.test.ts tests/tempo-tracker.test.ts
rust-anything build rust/work-hours-rs
rust-anything diff rust/work-hours-rs
rust-anything gate rust/work-hours-rs
```
