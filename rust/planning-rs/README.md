## Loop

Cases come from `inputs.jsonl` (20 zones × DST edges, skipped and repeated hours, invalid dates
and clocks, plan weights incl. NaN/±Infinity) plus the calls the planning tests make; generated
inputs are off (`--count 0`) because they pass arbitrary strings as IANA zones, where `Intl` throws
and relay-core reads UTC. `systemTimeZone`/`defaultPlanning` read the OS zone: the recording and
the diff both run with `TZ=UTC`.

Known deviation: `wallTime`/`wallTimeOrNext` on `0000-01-01` and `9999-12-31` (1040 cases): the TS
throws `RangeError: Invalid time value` (a ±36 h probe falls outside 4-digit years), relay-core
answers `undefined`. Also not covered: `localDate`/`localSlot`/`localHour` on a non-finite time
(TS throws, relay-core `""`/NaN).
