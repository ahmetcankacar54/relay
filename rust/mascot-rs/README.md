# mascot-rs

Rust port of `shared/mascot.ts`, bridged with napi-rs. Generated by rust-anything; `src/port.rs`
delegates to `relay_core::shared::mascot`, and `src/port/args.rs` turns the bindings' JSON
(`undefined` members, `{"$num": ...}` markers) into the relay-core types.

## Functions

- `activeReading` (`shared/mascot.ts:36`): returns the caller's own reading object, with
  `status: "ready"` in place of `"loading"`, as the TS spreads it (key order kept).
- `mascotRest` (`shared/mascot.ts:50`)
- `activeFull` (`shared/mascot.ts:64`)
- `mascotPose` (`shared/mascot.ts:69`)
- `headFor` (`shared/mascot.ts:107`): a string that is no pose gets the idle head, as the TS
  conditional gives it.

A missing `now` is `Date.now()`, read from `src/port/pinned.rs`. The `MascotInput` is read as a
`TraySnapshot` (its superset in relay-core, `TraySnapshot::mascot_input`). An account cast from a
partial object (`{ id, name } as Account`, as `menuBarPreview` builds one) gets empty values for
the fields the panda never reads, where relay-core's `Account` requires them.

`shared/mascot-frames.ts` exports no functions (constants and a record only), so rust-anything has
nothing to bridge there; its port, `relay_core::shared::mascot_frames`, is checked by
`crates/relay-core/tests/mascot.rs`.

## Loop

Cases are the calls the tests make (the mascot tests and every test that reaches the unit through
`shared/tray.ts` or the tray mascot) plus `inputs.jsonl` (every pose's head, and readings that are
fresh, full, loading, stale and expired, with Claude open and closed, with and without `now`).
Generated inputs are off (`--count 0`): they pass arbitrary JSON where the TS types name
`MascotInput`.

```sh
rust-anything record rust/mascot-rs --count 0 --pin-clock --inputs rust/mascot-rs/inputs.jsonl \
  --from-tests -- node --import tsx --test tests/mascot.test.ts tests/tray.test.ts \
  tests/tray-mascot.test.ts tests/tray-panel.test.ts tests/menu-bar-title.test.ts
rust-anything build rust/mascot-rs
rust-anything diff rust/mascot-rs
rust-anything gate rust/mascot-rs
```
