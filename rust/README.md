`rust/` holds rust-anything's parity material for the Rust port (`crates/`): `cli-inputs.jsonl` and the CLI recording in `app-cases/` (each case runs on a fresh fixture via `scripts/parity/fixture-run.mjs`), `gateway-inputs.jsonl` and the gateway recording in `gateway/rust/app-cases/` (`scripts/parity/gateway-run.mjs`, fake providers on 18401–18403), the frozen fixture homes in `fixtures/`, and the `<unit>-rs` crates (`rust-anything build rust/<unit>-rs && rust-anything diff rust/<unit>-rs`).

The `<unit>-rs` crates keep their recorded cases as `cases.jsonl.gz` (about 80 MB unpacked): run `node scripts/parity/cases.mjs unpack` before `rust-anything diff`/`gate`, and `node scripts/parity/cases.mjs pack` after a new `rust-anything record`. Each one's TS original in `shared/` is still part of the UI. The cases of units whose TS original went with the Tauri cutover (adaptive-plan, extension-auth, limit-calibration, statusline, tray-panel, widget-snapshot) moved to `crates/relay-core/tests/cases/` and replay in `cargo test -p relay-core --test recorded_cases`.

`fixtures/<scenario>/` is the world a recorded case starts from (`RELAY_PARITY_SCENARIO`; `default` for none), and `fixtures/<scenario>.json` its environment, folder and file modes. They were built by `scripts/parity/fixture-home.ts` through the Electron core, clock pinned at `RELAY_PARITY_NOW` 2026-11-26T09:41:15.000Z, and frozen before the cutover deleted it (`git log -1 --format=%h -- scripts/parity/fixture-home.ts` names the deleting commit; `git show <commit>^:scripts/parity/fixture-home.ts` shows it). `fixture-run.mjs` copies one into a new temp folder, filling in its placeholders: `@ROOT@` (that folder), `"@PID@"` (the live holder of a busy lock) and `@CRED-<account id>@` (Claude Code's per-profile keychain service).

The TS CLI (`cli/src`) is gone: the Rust `relay` replaced it in 0.2.0, so the CLI and gateway recordings are frozen and replay only against a build. Re-recording needs the TS CLI and the parity scripts from before the cutover (check out the commit before the one `git log -1 --format=%h -- scripts/parity/fixture-home.ts` names, and follow that commit's `rust/README.md`).

Replay the Rust build (`cargo build -p relay-cli --release --features parity`, macOS only; CI's `parity` job) with `rust-anything app replay . --build "node scripts/parity/fixture-run.mjs target/release/relay"` and `rust-anything app replay rust/gateway --build "node ../../scripts/parity/gateway-run.mjs ../../target/release/relay"`.
