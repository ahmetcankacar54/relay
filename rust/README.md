`rust/` holds rust-anything's parity material for the Rust port (`crates/`): `cli-inputs.jsonl` and the CLI recording in `app-cases/` (each case runs on a fresh fixture via `scripts/parity/fixture-run.mjs`), `gateway-inputs.jsonl` and the gateway recording in `gateway/rust/app-cases/` (`scripts/parity/gateway-run.mjs`, fake providers on 18401–18403), and the `<unit>-rs` crates (`rust-anything build rust/<unit>-rs && rust-anything diff rust/<unit>-rs`).

The `<unit>-rs` crates keep their recorded cases as `cases.jsonl.gz` (about 80 MB unpacked): run `node scripts/parity/cases.mjs unpack` before `rust-anything diff`/`gate`, and `node scripts/parity/cases.mjs pack` after a new `rust-anything record`.

The TS CLI (`cli/src`) is gone: the Rust `relay` replaced it in 0.2.0, so the CLI and gateway recordings are frozen and replay only against a build. Re-recording needs the TS CLI back from before its deletion (`git log -1 --format=%h -- cli/src` names the deleting commit; restore with `git checkout <commit>^ -- cli/src scripts/build-cli.mjs`, build it with `node scripts/build-cli.mjs`), then `rust-anything app record . --inputs rust/cli-inputs.jsonl --normalize timestamps --normalize uuids --normalize 'fixture-root=[^\s"'"'"'=]*relay-parity-[A-Za-z0-9]{6}' --name relay -- node scripts/parity/fixture-run.mjs cli/dist/relay.js` and `rust-anything app record rust/gateway --port 18317 --inputs rust/gateway-inputs.jsonl --normalize timestamps --normalize uuids --normalize 'uptime="uptimeSeconds":\d+' -- node ../../scripts/parity/gateway-run.mjs ../../cli/dist/relay.js`.

Replay the Rust build (`cargo build -p relay-cli --release --features parity`, macOS only; CI's `parity` job) with `rust-anything app replay . --build "node scripts/parity/fixture-run.mjs target/release/relay"` and `rust-anything app replay rust/gateway --build "node ../../scripts/parity/gateway-run.mjs ../../target/release/relay"`.
