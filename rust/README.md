`rust/` holds rust-anything's parity material for the Rust port (`crates/`): `cli-inputs.jsonl` and the CLI recording in `app-cases/` (each case runs on a fresh fixture via `scripts/parity/fixture-run.mjs`), `gateway-inputs.jsonl` and the gateway recording in `gateway/rust/app-cases/` (`scripts/parity/gateway-run.mjs`, fake providers on 18401–18403), and later the `<unit>-rs` crates; record the original with `npm run build:cli && rust-anything app record . --inputs rust/cli-inputs.jsonl --normalize timestamps --normalize uuids --normalize 'fixture-root=[^\s"'"'"'=]*relay-parity-[A-Za-z0-9]{6}' --name relay -- node scripts/parity/fixture-run.mjs cli/dist/relay.js` and `rust-anything app record rust/gateway --port 18317 --inputs rust/gateway-inputs.jsonl --normalize timestamps --normalize uuids --normalize 'uptime="uptimeSeconds":\d+' -- node ../../scripts/parity/gateway-run.mjs ../../cli/dist/relay.js`, and replay the Rust build (`cargo build -p relay-cli --release --features parity`, macOS only) with `rust-anything app replay . --build "node scripts/parity/fixture-run.mjs target/release/relay"` and `rust-anything app replay rust/gateway --build "node ../../scripts/parity/gateway-run.mjs ../../target/release/relay"`.
